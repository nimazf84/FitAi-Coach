# FitAi-Coach

FitAI Coach ist eine moderne Fitness-Anwendung, die mit Python und Tkinter entwickelt wurde.

Funktionen
 • BMI-Berechnung
 • Berechnung des täglichen Kalorienbedarfs
 • Personalisierte Trainingspläne
 • Modernes Dark-Mode-Design
 • Bildauswahl
 • Deutsche Benutzeroberfläche

Technologien
 • Python
 • Tkinter
 • GUI-Entwicklung

Projektbeschreibung

Die Anwendung analysiert Fitnessdaten wie Alter, Größe, Gewicht und Trainingsziele.
Anschließend werden BMI und täglicher Kalorienbedarf berechnet sowie individuelle Trainingsvorschläge erstellt.
